# «Синопсис музыки»: итоговый перевод и как он сделан

**Состояние на 1.11.2026.** Сводный русский и английский перевод с примечаниями собран, проверен и сверен с источниками. Это ещё черновик:
- редактор его пока не подписал;
- у редактора остаются 19 открытых вопросов (поле `open` в единицах `translation.json`).

На сайт перевод ещё не выложен.

| Файл | Что это |
|---|---|
| [translation.md](translation.md) | Перевод для чтения: греческий, русский, английский, 142 примечания, список литературы. |
| [translation.json](translation.json) | То же в данных. Для каждой единицы: `ru`, `en`, `notes` (с якорями, источником, отметкой проверки), `basis` (из каких переводов взято), `decisions` (карточки), `verify` (что исправляли проверяющие), `open` (вопросы редактору). |
| [independent/](independent/) | Шесть независимых переводов, A–F, с моделями в именах файлов. |
| [comparisons/](comparisons/) | Три сравнения шести переводов и данные, которые получили сравнивающие. |
| [decisions/](decisions/) | Решения редактора и исследование терминов. |
| [logs/](logs/) | Журналы сборки, проверки, согласования и сверки с источниками: каждое изменение с причиной. |
| [scripts/](scripts/) | Скрипты всех шагов. |

В файлах локальные пути заменены метками: `<ws-cmp>` (рабочая папка сравнения), `<runs>` (папка запусков вне репозитория), `<repo>`, `<tmp>`.

## Как сделан перевод

### 1. Шесть независимых переводов (31.10.2026)

Задание и пакет: [../independent/](../independent/). Переводили с установленного текста ([../constituted/text.json](../constituted/text.json)), 67 единиц. На сравнении переводы были обезличены метками.

| Метка | Переводчик | Среда |
|---|---|---|
| A | Claude Sonnet 5.5 | агент Claude Code, effort max |
| B | GPT-6.1 Terra | Codex CLI, ultra |
| C | Kimi K3 | приложение GitHub Copilot, reasoning High; запустил редактор |
| D | GPT-6 Astra | Codex CLI, ultra |
| E | Claude Opus 5.5 | агент Claude Code, effort max |
| F | GPT-6.1 Sol | Codex CLI, ultra |

### 2. Три сравнения

Сравнивающие видели только метки A–F, греческий текст и задание переводчиков ([comparisons/inputs/](comparisons/inputs/)).

- **Claude** ([comparisons/claude.json](comparisons/claude.json)). Workflow из четырёх групп: в каждой сравнение и состязательная проверка. Плюс сводка терминов.
- **GPT-6.1 Sol** в Codex ([comparisons/sol.json](comparisons/sol.json), [.md](comparisons/sol.md)), ultra, с поиском в сети. Sol — это переводчик F.
- **GPT-6 Astra** в Codex ([comparisons/astra.json](comparisons/astra.json), [.md](comparisons/astra.md)). Запустил редактор, разрешены субагенты. Проверка журналов показала, что Astra не выходила за свою папку.

Оба GPT-рецензента чаще всего выбирали лучшими GPT-переводы (D, F, B); это учитывалось при сведении. Ошибки, которые нашёл только один рецензент, перепроверены вручную: [comparisons/single-major-recheck.txt](comparisons/single-major-recheck.txt).

**Поправка.** Claude-рецензент счёл ошибкой «двойное сверхчастное» у F (U040–U041), но это не ошибка. F следует словоупотреблению Цыпина: «сверхчастные» = ἐπιμερεῖς, «сверхчастичные» = ἐπιμόριοι. Итоговый текст следует решению P03 и даёт отношение в скобках: «двукратное сверхчастное [8:3]».

### 3. Решения редактора (30–31.10.2026)

- 15 общих правил (P01–P15) и 15 мест (L01–L15): [decisions/cards.md](decisions/cards.md), ответы — [decisions/editor-decisions.txt](decisions/editor-decisions.txt).
- По спорным терминам проведено отдельное исследование со ссылками на словари, теоретиков и русскую и английскую научную традицию ([decisions/term-research.md](decisions/term-research.md)). После него редактор выбрал заново по шести карточкам: P02 b, P03 a, P06 b, P09 b, P10 a, P11 a.
- Сводка всех решений для сборки, правила примечаний и таблица отношений: [decisions/DECISIONS.md](decisions/DECISIONS.md). Глоссарий: [decisions/glossary.md](decisions/glossary.md).

### 4. Сборка (31.10–1.11.2026, Claude Opus 5.5)

- **Сборщики.** Шесть сборщиков составили текст по участкам. Каждый работал с греческого, используя шесть переводов, три рецензии, аппарат издания и решения. Задание: [logs/compose-brief.md](logs/compose-brief.md).
- **Проверяющие.** Трое состязательных проверяющих сверили участки с греческим и исправили найденное ([logs/verify-log-*.md](logs/)).
- **Согласование.** Последний читатель свёл термины, перекрёстные ссылки и формы ссылок по всему тексту, 165 правок ([logs/consistency-log.md](logs/consistency-log.md)).

### 5. Сверка с источниками и вычитка (1.11.2026)

- **Источники.** Каждую ссылку в примечаниях проверили по самим источникам в сети, по участкам ([logs/factcheck/notes-*.md](logs/factcheck/)):
  - Теон по страницам Хиллера, Ян, Гохе;
  - LSJ, DGE, Bailly, Pape;
  - Платон, Аристотель;
  - Щетников, Цыпин.
- **Перевод и язык.** Независимое прочтение перевода по греческому ([reading-accuracy.md](logs/factcheck/reading-accuracy.md)) и редакторская вычитка обоих языков ([reading-language.md](logs/factcheck/reading-language.md)).
- **Литература.** Список литературы дополнен по каталогам ([bibliography.md](logs/factcheck/bibliography.md)).
- **Исправления.** Трое проверяющих отсеяли ложные находки и внесли подтверждённые исправления, 72 правки ([apply-*.md](logs/factcheck/)). Например:
  - формула «единица не рассекается» найдена у Теона на с. 70 Hiller, а не на с. 66;
  - Теон приводит полутон 17:16 лишь как рабочую меру;
  - с. 56–57 Хиллера ошибочно приписывались Адрасту.
- Чего проверить в сети не удалось, перечислено в журналах. Это страницы Баркера (GMW II), Лампе, Герцман 2010 и формулировки Цыпина 2013.

Решения редактора проверяющие не меняли: вопросы к ним записаны в поле `open`.

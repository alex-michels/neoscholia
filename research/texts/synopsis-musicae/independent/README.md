# Независимый перевод «Синопсиса музыки» (анонимное «Четверокнижие» 1008 г.)

По методу Neoscholia каждый текст переводится не меньше двух раз, независимо, моделями разных семейств. Один перевод делают модели Claude. Другой делает модель GPT в Codex — по тому же греческому тексту, не видя первого перевода.

## Состояние: ждёт установленного текста

Перевод начнётся только после установления греческого текста (решение редактора, 27.10.2026):
1. **Транскрипция и вычитка — дважды, независимо.** Claude и GPT-6. Пакет для GPT — [../independent-text/](../independent-text/).
2. **Сведение** транскрипций, вычиток и критики → один греческий текст с аппаратом.
3. **Перевод** — новые сессии, параллельно и независимо, по этому одному тексту.

Свидетели текста: [../WITNESSES.md](../WITNESSES.md); план: [../PLAN.md](../PLAN.md).

## Что будет в папке

- `PROMPT.md` — задание. **Готово**; перед запуском — сверить описание текста с установленным текстом:
  - основа — Базель 1556, исправленная по Pal. gr. 281;
  - аппарат наш, а не Гейберга;
  - три места Paris. gr. 2448 — в ⟨ ⟩.
- `greek-text.json` — установленный греческий текст по разделам, со ссылками на страницы Базеля и листы Pal. gr. 281, с аппаратом. Места Paris. gr. 2448 — в угловых скобках ⟨ ⟩, с пометой «только Paris. gr. 2448; нет в Pal. gr. 281 и в изданиях». **После сведения.**
- `glossary.json` — согласованные русские и английские термины гармоники. **Составляется.**
- `about.md` — справка: «Четверокнижие» 1008 г., датировка, ошибочная атрибуция Пселлу, свидетели, сиглы, место раздела о музыке. **Черновик есть, войдёт после сведения.**

В пакет не войдут никакие переводы: ни латынь Ксиландра и Вине, ни немецкий Мицлера, ни французский Венсана, ни современные. Сверка с ними — отдельный редакторский шаг после обоих независимых переводов.

## Как запустить, когда пакет будет готов

1. Откройте **новую** сессию Codex так, чтобы рабочей папкой была эта папка: `Neoscholia\research\texts\synopsis-musicae\independent`.
2. Выберите модель GPT-6 (или GPT-6.1 Sol), режим Ultra.
3. Разрешите доступ в интернет.
4. Дайте задание: «Выполни задание из файла PROMPT.md».
5. Проверьте, что появились `draft-<модель>.json` и `draft-<модель>.md`.

# Независимые переводы «Синопсиса музыки» (анонимное «Четверокнижие» 1008 г.)

Шесть независимых научных критических переводов — на русский и на английский — с одного установленного греческого текста. Переводчики работают параллельно, по одному заданию, каждый в своей изолированной папке вне репозитория и вне `Neoscholia-runs`, и не видят друг друга.

## Пакет

- [PROMPT.md](PROMPT.md) — задание, одно для всех. При запуске `{FOLDER}` заменяется путём папки переводчика; больше ничего не меняется. В задании:
  - роль переводчика;
  - правила независимости;
  - источники;
  - порядок работы;
  - принципы перевода;
  - формат выдачи (`translation.json`, `translation.md`).
- [about.md](about.md) — справка: о сочинении, свидетели и сиглы, знаки издания, как читать аппарат, русская терминология Цыпина по переводам *других* теоретиков.
- [greek-text.json](greek-text.json) — установленный текст ([../constituted/text.json](../constituted/text.json)), разбитый на 67 единиц перевода по предложениям. В каждой единице:
  - ссылка на строки Базеля;
  - пометы мест Paris. gr. 2448 с номером фрагмента у Венсана.

  К тексту приложены записи аппарата (81) без примечаний издания. Строится скриптом [../transcriptions/tools/build_translation_units.py](../transcriptions/tools/build_translation_units.py); скрипт проверяет, что единицы покрывают текст ровно.

## Что не вошло, чтобы не направлять перевод

- **Чтения для переводчика** (`alternatives_for_translation` в text.json): в них наши английские толкования.
- **Примечания к аппарату** и **решённые сомнения**: в них доводы издания.
- **Непроверенный глоссарий** (`work/glossary-draft.json`). Термины каждый переводчик выбирает сам и обосновывает в `terms`.

Запрещены:
- любые переводы этого текста: латинские, немецкий Мицлера, французский Венсана, современные;
- работы о нём;
- издание Хайберга;
- поздние византийские авторы, которые его переиспользуют;
- поиск в сети по его фразам, редким словам и названиям.

# Независимая транскрипция и вычитка греческого текста «Синопсиса музыки» (GPT, до перевода)

Перевод в Neoscholia идёт только после установления текста. Текст тоже устанавливается дважды, независимо, моделями разных семейств:
- **Claude** — своя транскрипция и сверка (workflow в основной сессии);
- **GPT-6** — по этому заданию, в отдельной сессии Codex.

Порядок (решение редактора, 27.10.2026):
1. **Транскрипция и вычитка** — одна сессия GPT-6 по этому заданию; параллельно Claude.
2. **Сведение.** Несколько параллельных транскрипций, вычиток и критики сравниваются построчно; расхождения решаются по сканам. Получается один греческий текст с аппаратом.
3. **Перевод** — новые сессии, тоже параллельно и независимо, с этого одного текста: [../independent/](../independent/).

Латинские переводы Ксиландра и Вине транскрибируются отдельно, в другой сессии GPT-6: [../independent-latin/](../independent-latin/).

## Задание

[PROMPT.md](PROMPT.md). Сиглы:
- H — Pal. gr. 281, 1040 г.;
- V — Vat. Pal. gr. 262;
- Par. — Париж 1545;
- Bas. — Базель 1556, основа ссылок;
- P — Paris. gr. 2448 по Венсану.

Что делает GPT:
- полные транскрипции Bas. и H;
- сверка Par. и V с Bas.;
- три фрагмента P и проверка их мест во всех свидетелях;
- исправленный текст: места, которые есть только в P, — в ⟨⟨ ⟩⟩;
- всё — с едиными правилами счёта строк и ссылок, чтобы сравнивать построчно с транскрипцией Claude.

Промпт дважды проверен отдельными агентами на утечки наших результатов, противоречия и выполнимость (27.10.2026) и исправлен по замечаниям. Единые знаки для неуверенных букв, раскрытий, красных чернил, исправлений и пунктуации нужны, чтобы транскрипции GPT и Claude сравнивались построчно.

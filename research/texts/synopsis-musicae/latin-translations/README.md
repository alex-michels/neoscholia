# Латинские переводы «Синопсиса Музыки»: Ксиландр и Вине на русском и английском

**Состояние на 21.11.2026.** Четыре независимых перевода обоих латинских текстов готовы и сравнены вслепую тремя рецензентами. Следующий шаг — решения редактора по спорным местам.

Два латинских перевода XVI в.:
- **Ксиландр**, Базель 1556, с. 40–49;
- **Вине**, Турнон 1591, с. 41–53.

Их переводят на русский и английский для вкладки «Старые переводы» (решение редактора, [../PLAN.md](../PLAN.md), § 6). Цель — показать, как поняли текст сами переводчики XVI в. Поэтому переводят только с латыни, без греческого оригинала и без нашего перевода. Сравнение латыни с греческим — отдельный будущий шаг.

## Подготовка

1. **Читаемый текст** — [reading-texts.json](reading-texts.json), скрипт [scripts/build_reading.py](scripts/build_reading.py).
   - Основа — нормализованный текст из транскрипции GPT-6 Astra.
   - Он сверен слово в слово со сведённой дипломатической транскрипцией ([../transcriptions/](../transcriptions/)), установленной дважды, Claude и GPT-6 Astra.
   - Скрипт допускает только перечисленные расхождения: исправления опечаток (у Ксиландра 3, у Вине 13) и разбивку слов. На всём остальном он останавливается.
2. **Привязка к единицам греческого текста** — [alignment.json](alignment.json).
   - Каждый латинский текст разрезан на отрезки по 67 единицам греческого текста: у Ксиландра 58 отрезков, у Вине 66. Девяти единиц, сохранившихся только в P, в латыни нет.
   - Резали два агента Claude Opus 5.5, по одному на текст, по греческому и латыни. Каждую границу проверил второй агент, ошибок не нашёл.
   - Отрезки воспроизводят читаемый текст в точности; это проверяет скрипт сборки.
3. **Пакет для переводчиков** — [independent/](independent/):
   - [PROMPT.md](independent/PROMPT.md) — задание;
   - [about.md](independent/about.md) — справка и принятые термины;
   - [latin-texts.json](independent/latin-texts.json) — тексты; собирает [scripts/build_package.py](scripts/build_package.py);
   - сканы страниц, которые в git не хранятся; папку переводчика собирает [scripts/make_run_folder.py](scripts/make_run_folder.py).

   Метки единиц в пакет не входят: они показали бы, где в греческом есть места без латинского соответствия. Метки лежат отдельно, в [segment-map.json](segment-map.json).
   - **Проверка на утечки.** Отдельный агент проверил пакет до запуска. По его замечаниям убраны метки единиц и правила, которые подсказывали толкование отдельных мест, и исправлены описания данных.
   - **Английские названия отношений** (duple, sesquialter, sesquitertian, sesquioctave, duple superpartient) взяты из перевода Боэция К. Бауэром (1989). Латинские переводчики сами пользуются боэциевскими названиями.
   - **Русские кальки** («полуторное», «сверхтретное», «сверхосминное», «двукратное сверхчастное») — те же, что у Цыпина и С. Н. Лебедева. Справку по этим терминам агент свёл по самим источникам.

## Четыре перевода (20.11.2026)

Все четыре перевода в [translations/](translations/), имена моделей в именах файлов. На сравнении переводы будут обезличены метками A–D.

| Метка | Переводчик | Среда | Отрезки | Примечания |
|---|---|---|---|---|
| A | Claude Fable 5.2 | workflow агентов Claude: переводчик и ревизор на каждый текст, затем сборщик | 58 + 66 | 104 |
| B | GPT-6.2 Sol | приложение Codex, Ultra, интернет, субагенты; запустил редактор | 58 + 66 | 85 |
| C | Claude Opus 5.5 | workflow агентов Claude, как у A | 58 + 66 | 131 |
| D | GPT-6.2 Astra | приложение Codex, Ultra, интернет, субагенты; запустил редактор | 58 + 66 | 99 |

- **Как переводы назвали себя.** GPT-модели назвали себя только «GPT-6 (Codex)»: точный номер им недоступен. Версии записаны по запуску.
- **Журналы правки.** Журналы ревизоров A и C лежат в [logs/](logs/). Скрипт workflow — [scripts/translate-workflow.js](scripts/translate-workflow.js).
- **Журналы сессий Codex (B, D) проверила Claude.** Обе модели работали только в своей папке и открывали словари (Lewis & Short, Gaffiot, Du Cange, ThLL, Logeion), Боэция, теоретиков и грамматики. Ни греческого текста «Синопсиса», ни его переводов, ни исследований о нём в журналах нет.
- **Случайные находки.** Все переводчики записали их в `contamination`, ни одна не использована:
  - **D и B:** поисковые сниппеты, не открыты.
  - **A:** заголовок книги Е. В. Герцмана в результатах поиска, не открыт.
  - **C:** сноска в издании К. фон Яна (Musici scriptores Graeci, с. 338, к Гауденцию, гл. 8) цитирует строку греческого текста «Синопсиса» под именем Пселла. Переводчик Ксиландра увидел её и бросил читать. Примечания к Вине (V36) берут с этой страницы только определение парафонии у Гауденция. На сравнении места X31–X32 и V36–V37 в версии C проверить особо. В будущих заданиях предупреждать, что аппарат Яна цитирует «Синопсис».

## Замечания переводчиков о данных, для следующего шага

- X34: запятая в «unoque, semitonio» есть только в читаемом тексте, в печати её нет (A).
- Вине, с. 49: схема длин струн без подписи в отрезках не отражена (A; описана в примечании к V42).
- Предложения по тексту, перечисленные в `text_issues`. Чаще всего названы X24 «quod propositum dupli esse constat», X23 «Numerorum» и X38 «qua … habet».

## Три слепых сравнения (20–21.11.2026)

Сравнивающие видели только латынь, задание переводчиков, справку и переводы под метками A–D; порядок меток менялся от отрезка к отрезку. Входные данные — [comparisons/inputs/](comparisons/inputs/), их собирает [scripts/build_cmp_inputs.py](scripts/build_cmp_inputs.py). Из примечаний переводчиков убраны ссылки и названия сайтов, по которым узнавались бы модели. Задание — [comparisons/inputs/PROMPT-codex.md](comparisons/inputs/PROMPT-codex.md).

| Сравнение | Среда | Расхождения (к редактору) | Серьёзные ошибки A / B / C / D | Чаще всего лучшая основа |
|---|---|---|---|---|
| [Claude](comparisons/claude.json) ([.md](comparisons/claude.md)) | workflow Claude Opus 5.5: сравнение и независимый скептик на каждую из четырёх групп, затем термины | 61 (34) | 0 / 1 / 0 / 0 | A и C |
| [GPT-6.2 Sol](comparisons/sol.json) ([.md](comparisons/sol.md)) | Codex, Ultra, субагенты; запустил редактор | 57 (21) | 3 / 3 / 1 / 1 | D и B |
| [GPT-6.2 Astra](comparisons/astra.json) ([.md](comparisons/astra.md)) | Codex, Ultra, субагенты; запустил редактор | 71 (33) | 5 / 4 / 8 / 1 | D и B |

- **Журналы сессий Codex проверила Claude.** Обе модели работали только в своей папке. Ни греческого текста «Синопсиса», ни его переводов, ни исследований о нём в журналах нет. Сайт проекта упоминается только как строка задания с запретом.
- **Перекос по семействам.** Каждое сравнение ставит выше переводы своего семейства: Claude — A и C, GPT — D и B. Поэтому сведение опирается на совпадения сравнений и на доводы, а не на число голосов.
- **Сведение и перепроверка.** Все три сравнения сведены по отрезкам в [comparisons/merged.json](comparisons/merged.json) скриптом [scripts/merge_comparisons.py](scripts/merge_comparisons.py).
  - Серьёзных ошибок, которые подтвердили два сравнения, — 11.
  - Ещё 16 нашло только одно сравнение. Их перепроверяют вслепую двое агентов разных моделей, Opus и Fable: им не говорят, чей перевод и чья претензия.

# Независимая транскрипция и вычитка латинских переводов «Синопсиса музыки» (GPT)

Два латинских перевода XVI в.:
- **Ксиландр** — Базель 1556, с. 40–49;
- **Вине** — Турнон 1591, с. 41–53, по главам и параграфам.

Они понадобятся на редакторском этапе, **после** обоих независимых переводов греческого текста: как учёные XVI в. понимали трудные места. Для этого нужны точная транскрипция и чистый читаемый текст каждого перевода, тоже в двух независимых исполнениях:
- **Claude** — Ксиландр уже транскрибирован и проверен (workflow 26–27.10.2026); Вине будет следующим;
- **GPT-6** — по этому заданию, в отдельной сессии Codex.

**Важно для независимости переводов.** Сессия, которая транскрибирует латынь, видела переводы. Поэтому она **не должна** потом переводить греческий текст. Перевод — только в новых сессиях, без доступа к этой папке.

## Задание

[PROMPT.md](PROMPT.md):
- **A** — дипломатическая транскрипция обоих текстов построчно, с теми же правилами, что у транскрипции Claude:
  - сокращения раскрываются без скобок;
  - ſ → s;
  - u/v, i/j, акценты и пунктуация — как напечатано;
- **B** — список опечаток;
- **C** — читаемый текст по абзацам: нормализованная орфография, исправленные опечатки;
- **D** — сопоставление параграфов Вине со страницами Ксиландра.

Греческого текста, других изданий и других переводов у GPT нет: задание только латинское. Сиглы: Xyl. и Vinet; полное имя у Вине — чтобы не путать с Vinc., Венсаном, в греческом задании. Промпт проверен отдельным агентом (27.10.2026) и исправлен по замечаниям.

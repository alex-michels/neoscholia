# Независимый перевод схолий к «Одиссее», песнь X (модель другого семейства)

По методу Neoscholia каждый текст переводится не меньше двух раз, независимо, моделями разных семейств. Первые переводы этих схолий сделаны моделями Claude: ст. 1–4 на странице «Схолии к „Одиссее“, песнь X», ст. 82–86 в приложении к статье о Кратете. Второй перевод делает модель GPT в Codex только по греческому тексту, не видя первого перевода.

В этой папке лежит только то, что нужно переводчику:
- `greek-scholia.json` — греческий текст схолий по Диндорфу. Набор A: ст. 1–4, текст по распознанному скану, ещё не сверен; переводчик сверяет его со сканами. Набор B: ст. 82–86, текст сверен. Есть сиглы, леммы, выборка из аппарата и строки Гомера;
- `PROMPT.md` — задание.

## Как запустить

1. Откройте **новую** сессию Codex так, чтобы рабочей папкой была эта папка: `C:\Users\user\Documents\Projects\Neoscholia\research\texts\odyssey-scholia\independent`.
2. Выберите модель: GPT-6 Astra или GPT-6.1 Sol.
3. Разрешите доступ в интернет: переводчику нужны сканы Диндорфа, Евстафия, Гемина и схолий к Арату.
4. Дайте задание: «Выполни задание из файла PROMPT.md».
5. Проверьте, что появились `draft-<модель>.json` и `draft-<модель>.md`.

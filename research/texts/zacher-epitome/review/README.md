## Что где лежит

- **Промпт для рецензента:** [`PROMPT.md`](PROMPT.md).
- **Перевод для рецензии:** `book1-for-review.md` — в этой папке. По каждой главе: латынь, русский, английский, примечания.
- **Оригинал:**
  - `../source/book1.la.json` — латынь по главам;
  - `../source/epitome.tei.xml` — полный TEI, Zacher 1867, CC0.
- **Справочные файлы:**
  - `../glossary.json` — имена и термины;
  - `../context.json` — параллели и библиография;
  - `../reviews/` — рецензии моделей Claude.
  - `../arbitration-log.md` — как решено каждое замечание этих рецензий.
- **Куда рецензент пишет результат:** `external/<модель>.json` и `external/<модель>.md`.

## Как запустить в Codex

1. Откройте Codex в корне репозитория (`Neoscholia`). Он должен видеть папку `research/`.
2. Выберите модель, например GPT-6.1 Sol или GPT-6 Astra.
3. Дайте задание: «Выполни задание из файла `research/texts/zacher-epitome/review/PROMPT.md`».
4. Если у Codex есть доступ в интернет, разрешите его: так он сможет сверить примечания с изданиями Юлия Валерия и Псевдо-Каллисфена.
5. Проверьте, что появились оба файла в `external/`, и сделайте коммит.

Можно прогнать несколько моделей: каждая пишет файлы под своим именем.

Промпт [`PROMPT.md`](PROMPT.md) написан для версии 0.2; для следующей рецензии его нужно обновить под версию 0.3. Рецензент проверяет статью заново и отдельно оценивает, как версия 0.2 учла каждое из 14 замечаний GPT-6.1 Sol. Промпт для версии 0.1 — в истории git.

## Как запустить в Codex

1. Откройте Codex в корне репозитория (`Neoscholia`).
2. Выберите модель: GPT-6 Astra.
3. Дайте задание: «Выполни задание из файла `research/studies/laestrygonians/review/PROMPT.md`».
4. Разрешите доступ в интернет: рецензенту нужны сканы изданий, каталоги и литература. Разрешите и запуск Python, чтобы он мог пересчитать астрономию скриптами из `code/`.
5. Проверьте, что в `external/` появились `gpt-6-astra.json` и `gpt-6-astra.md`, а `gpt-6.*` не изменились.

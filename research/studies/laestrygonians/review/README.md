# Внешняя рецензия препринта (модели другого семейства)

Статья «Пергам против Александрии? Кратет, Аристарх и „короткие ночи“ лестригонов» подготовлена и проверена моделями Claude. Рецензия моделями другого семейства, например GPT через Codex, делает проверку перекрёстной.

## Как запустить в Codex

Порядок одинаковый для GPT-6 Astra и для GPT-6.1 Sol:

1. Откройте Codex в корне репозитория (`C:\Users\user\Documents\Projects\Neoscholia`).
2. Выберите модель.
3. Дайте задание: «Выполни задание из файла `research/studies/laestrygonians/review/PROMPT.md`».
4. Разрешите доступ в интернет: рецензенту нужны сканы изданий, каталоги и литература. Разрешите и запуск Python, чтобы он мог пересчитать астрономию скриптами из `code/`.
5. Проверьте, что в `external/` появились `<модель>.json` и `<модель>.md`, и сделайте коммит.

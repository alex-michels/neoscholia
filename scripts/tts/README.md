# Озвучка переводов (Silero)

Переводы на страницах текстов можно слушать: у каждой главы кнопка «Слушать» / «Listen». Звук записан заранее синтезом речи и лежит на сайте как обычные MP3-файлы, поэтому сайт остаётся статическим.

- Русский: Silero `v5_6_ru`, голос `xenia`. Английский: Silero `v3_en`, голос `en_0`.
- Модели: [snakers4/silero-models](https://github.com/snakers4/silero-models). В файле LICENSE репозитория — CC BY-NC-SA 4.0, в README — CC BY-NC; для некоммерческого сайта подходит любая, авторство Silero указывается на странице текста.
- Файлы: `src/assets/audio/<текст>/<язык>/c<глава>-<отпечаток>.mp3`, список — `src/_data/audio/<текст>.json`.

## Почему озвучка не расходится с текстом

Отпечаток — первые 10 знаков SHA-1 текста перевода главы в `src/_data/texts/<текст>.json`. Сборка сайта считает отпечаток заново (фильтр `textHash` в `eleventy.config.js`) и показывает кнопку, только если он совпадает с записанным. Поправили главу — кнопка у неё пропадёт до новой озвучки.

## Как озвучить

Нужны Python 3.10–3.12 и ffmpeg в PATH. Окружение держите вне репозитория:

```bash
py -3.12 -m venv %LOCALAPPDATA%\neoscholia-tts\venv
%LOCALAPPDATA%\neoscholia-tts\venv\Scripts\pip install torch --index-url https://download.pytorch.org/whl/cpu
%LOCALAPPDATA%\neoscholia-tts\venv\Scripts\pip install numpy
```

Затем из корня проекта:

```bash
%LOCALAPPDATA%\neoscholia-tts\venv\Scripts\python scripts/tts/tts.py zacher-1
```

Скрипт озвучит только главы, которых нет или которые изменились. Модели (около 200 МБ) при первом запуске скачаются с models.silero.ai в `%USERPROFILE%\.cache\neoscholia-tts` (другое место — переменная `NEOSCHOLIA_TTS_CACHE`).

Полезные ключи:
- `--lang ru` или `--lang en` — один язык;
- `--chapters 14,15` — только эти главы;
- `--force` — озвучить заново, даже если текст не менялся (например, после правки словаря ударений).

На обычном ноутбуке без видеокарты книга I Цахера озвучивается примерно за полчаса: русский быстрее, английский медленнее.

## Ударения

Silero сам расставляет ударения, но в именах и редких словах ошибается. Поправки — в [`stress-ru.txt`](stress-ru.txt): строка «основа = основа с плюсом перед ударной гласной», например `Нектанеб = Нектан+еб`. Основа ищется с начала слова и подходит ко всем падежам. После правки словаря озвучьте нужные главы заново с `--force`.

Квадратные скобки редакции («тот [Александр]») голос не читает как скобки: слово внутри произносится, скобки снимаются.

# Данные разделов библиотеки

Один файл — одна страница раздела: `music.yaml` → `music.html`. Страницу собирает шаблон
[`../../_includes/section-body.njk`](../../_includes/section-body.njk); сама страница `src/music.njk` — только шапка
(заголовок вкладки, «хлебные крошки», уведомление) и строка `{% include "section-body.njk" %}`.

Значения полей — обычный текст; где нужно, в нём можно писать HTML (ссылки, `<span lang="grc">…</span>`).
Номер версии опубликованного текста не пишется от руки: `{version:zacher-1}` подставит текущую версию страницы
`zacher-1.html`. Подстановка работает в `intro`, `facts[].text`, в строках карты (`have`, `gap`), в `plan` и `tr`
записей каталога; в остальных полях номер версии не пишут.

## Поля

| Поле | Что это |
|---|---|
| `h1` | заголовок страницы |
| `intro` | абзацы вступления |
| `editor` | строка «Раздел ведёт: …» |
| `facts` | справка под вступлением: список `{ label, text }`; `factsAside: true` ставит её в правую колонку вместо рисунка |
| `figure` | рисунок в правой колонке: файл из `src/_includes/sections/` |
| `blocks` | порядок блоков страницы (см. ниже) |
| `related` | «Уже в библиотеке»: `id` (якорь заголовка, например `have-h`), `title`, `note`, `items: [{ href, title, text }]` |
| `map` | карта корпуса: `id` (якорь заголовка), `title`, `note`, `label` (подпись таблицы для чтения с экрана), `head` (три заголовка столбцов; второй и третий подписывают ячейки на узком экране), `legend: [{ dot или star: true, text }]`, `rows` |
| `catalogue` | каталог текстов: `id`, `title`, `note`, `filterLabel` (подпись группы фильтров), `all` (текст первой кнопки, «Все»), `groups: [{ key, label }]`, `flag` (подпись флажка), `empty` (фраза, когда по фильтру ничего нет), `items` |
| `exists` | «Уже есть на русском»: `title`, `note`, `items` — пары `[произведение, переводчик и год]` |
| `studies` | «Исследования раздела»: `title`, `items: [{ title, note }]` |

`blocks` — список в том порядке, в каком блоки идут на странице: `related`, `map`, `catalogue`, `closing`
(«Уже есть на русском» + «Исследования раздела») или особый блок раздела:
`{ include: "sections/alexander-map.njk", title: "…", note: "…", id: "map-h" }`.

Блок «Опубликовано в разделе» в данных не описывается: он появляется сам, когда у страницы текста в шапке
есть `card` с `sectionHref`, равным адресу раздела.

## Карта корпуса (`map.rows`)

```yaml
- topic: Ритмика
  id: rhythm                  # якорь темы (необязательно)
  have:                       # уже по-русски
    - { dot: ru, text: "Аристоксен, «Элементы ритмики» II" }
  gap:                        # пробелы
    - { dot: none, text: "Пселл, «Предварения к ритмике»" }
  closed: "Ядро закрыто — повторно не переводим."   # вместо списка пробелов (необязательно)
  haveClosed: "Не найдено."                         # вместо списка «уже по-русски» (необязательно)
```

`dot`: `none` — нет по-русски, `part` — по-русски отрывки, `ru` — есть по-русски.
Звёздочка «в плане Neoscholia» ставится в тексте: `<b class="star">★</b>`.

## Запись каталога (`catalogue.items`)

```yaml
- group: byz                  # ключ группы из catalogue.groups: по нему работает фильтр и берётся подпись группы
  flag: true                  # красная линия сверху: флагман, первый пилот, опубликовано
  nowhere: true               # попадает под флажок «только не переведённые ни на один язык»
  plan: флагман               # подпись справа от группы; planMuted: true — серым (нужен соавтор, сверить статус)
  title: Георгий Пахимер, «Четверокнижие», кн. II: «Гармоника»
  href: synopsis-musicae.html # только у опубликованных: заголовок становится ссылкой, запись занимает всю ширину
  orig: Σύνταγμα τῶν τεσσάρων μαθημάτων   # название в оригинале; origLang: grc | la — язык всей строки
  info: ок. 1300 · греческий · ~100 страниц с диаграммами
  tr:                         # существующие переводы — чипы
    - { text: нет ни на одном языке, kind: none }   # залитый красный
    - { text: "RU: нет", kind: gap }                # красная рамка
    - "FR: только краткое изложение (1847)"         # нейтральный
  rows:                       # строки «Основа», «Первая часть», «Зачем» …
    - [Основа, "Tannery & Stéphanou 1940"]
```

Флажок фильтра показывается, только если в разделе есть хотя бы одна запись с `nowhere: true`.

Реестр разделов (название, адрес, описание на полке, тексты на странице «Библиотека») — в
[`../sections.yaml`](../sections.yaml).
